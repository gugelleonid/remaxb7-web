# remaxb7-web

Новый дизайн сайта RE/MAX B7 (Беэр-Шева). Сейчас работает на тестовом поддомене **https://new.remaxb7.co.il**.

- Источник: артефакт «קונספט REMAX באר שבע» (v0.9), файлы совпадают с ним до байта.
- Страницы: `index.html` (главная, 3D-фильм на скролле), `about.html`, `investments.html`, `academy.html`, `careers.html` (статичные, общие стили `assets/pages.css` и `assets/pages.js`). Тексты по брифу Шая Штерна (ноябрь 2026).
- Хостинг: сервер Hetzner `178.104.86.212`, Coolify. Сборка по `Dockerfile` (nginx), отдаётся как статика.
- Обновление: любой push в `main` → Coolify пересобирает и выкладывает сайт.
- Тестовый поддомен закрыт от поисковиков (`robots.txt` и заголовок `X-Robots-Tag` в `nginx.conf`).
  При переезде на основной домен `remaxb7.co.il` убрать оба запрета.
